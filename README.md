# Tutorial Platform

A flexible, interactive tutorial platform built with React and Vite. Create and manage step-by-step tutorials with YAML frontmatter and Markdown content.

Prerequisites
- Node.js (recommended v16+)
- npm

Install
- Install dependencies:
  npm install

Run the dev server
- Start dev server:
  npm run dev

The dev server typically runs at:
http://localhost:5173

Build and preview
- Build production bundle:
  npm run build
- Preview production build locally:
  npm run preview

Notes
- If the dev port is occupied, Vite will suggest an alternative port in the terminal.
